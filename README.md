# GBeauty Inventory Manager

## Description

GBeauty Inventory Manager is a simple inventory management application for a beauty supply store. It allows users to add products, view current inventory, and delete products. Product information is stored in a PostgreSQL database using Prisma and Neon.

## Features

- View all products
- Add a new product
- Delete a product
- Inventory summary
- Data is stored in a PostgreSQL database

## Technologies Used

- Next.js
- React
- Prisma ORM
- Neon PostgreSQL
- JavaScript
- CSS

## Running the Project

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and go to:

```
http://localhost:3000
```

## Database

This project uses Prisma with a Neon PostgreSQL database.

To seed the database:

```bash
npm run seed
```
